# 楽天MT4 リアルタイム連携 EA 設定ガイド

本ガイドは、楽天MT4（デモ口座）に `RakutenTradeAgent.mq4` を導入し、Rust Gateway とリアルタイム連携させる手順です。

---

## 1. MQL4 ファイルの配置手順

1. 楽天MT4を起動します。
2. 上部メニューから **[ファイル] -> [データフォルダを開く]** を選択します。
3. 開いたフォルダ内の `MQL4/Experts` ディレクトリに、本リポジトリの [`mql4/RakutenTradeAgent.mq4`](file:///c:/Users/yamat/OneDrive/デスクトップ/Docker%20Agent/mql4/RakutenTradeAgent.mq4) をコピーします。
4. MT4の「ナビゲーター」ウィンドウで **[エキスパートアドバイザ]** を右クリックし、**[更新]** を選択します。

---

## 2. MT4 のオプション設定（DLL許可）

TCPソケット通信（`ws2_32.dll`）を使用するため、DLLの呼び出しを許可します。

1. MT4メニューの **[ツール] -> [オプション]** を開きます。
2. **[エキスパートアドバイザ]** タブを選択します。
3. 以下の項目にチェックを入れます：
   - ✅ **自動売買を許可する**
   - ✅ **DLLの使用を許可する（信頼できるアプリケーションのみ）**
4. **[OK]** をクリックして保存します。

---

## 3. チャートへの適用と稼働

1. 楽天MT4で任意の通貨ペアチャート（例: `USDJPY`, `EURUSD` 1分足または5分足）を開きます。
2. ナビゲーターウィンドウから `RakutenTradeAgent` をチャートにドラッグ＆ドロップします。
3. パラメータ設定画面で以下を確認・調整します：
   - `ServerHost`: `127.0.0.1` (ローカルGatewayのIP)
   - `ServerPort`: `5555` (Gatewayのポート番号)
   - `DefaultLots`: `0.1` (ロット数)
   - `EnableAutoTrade`: `true`
4. チャート右上に **にこちゃんマーク（😊）** が表示されれば正常稼働中です。
