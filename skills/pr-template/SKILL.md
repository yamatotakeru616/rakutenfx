# PR 作成テンプレート

Pull Request を作成する際は、以下の構成に従って記述してください。

## 概要 (Overview)

- 今回の変更内容の簡潔なサマリー

## 変更理由・背景 (Motivation & Context)

- なぜこの変更が必要なのか、解決する問題や追加する機能の背景

## 主な変更点 (Key Changes)

- `path/to/file1`: 主な変更内容
- `path/to/file2`: 主な変更内容

## テスト内容・検証結果 (Testing & Verification)

- [ ] 単体テスト（Unit Tests）が通過していること
- [ ] 静的解析・型チェック（Linter / TypeCheck）が通過していること
- [ ] 動作確認手順および確認結果

## 関連Issue / ドキュメント

- Close #XX
